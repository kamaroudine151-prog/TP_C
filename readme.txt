ADOTEVI Téddy: Fonction grille4puissance (grille). Il gère l'affichage de la grille à l'écran, 
initialise les cases vides et affiche les pions avec leurs couleurs.

AHMAT Youssouf : Fonction init_jeu (Jeu). Il gère tout ce qui se passe avant que la partie commence : saisir 
les noms, choisir aléatoirement qui commence, attribuer les symboles et afficher les infos à l'écran.

KOUDORO Kamarou Dine : Fonction jouer_colonne. Son seul rôle est de vérifier si une colonne est pleine 
ou non avant qu'un joueur y joue.

KOUHOGBE Louange : Fonction verif_gain (verification). Après chaque coup joué, elle vérifie dans les 4 directions
si un joueur a aligné 4 pions, et si la grille est complètement remplie

KINSOU Prince : Fonction main. Il appelle toutes les fonctions dans le bon ordre et gère la boucle 
principale du jeu jusqu'à la fin de la partie.
    Fonction utils. Il contient les fonctions de base pour contrôler la console Windows.
